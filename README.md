# Mini Python Projects

My first Python projects, built while learning to code with AI.

## 1. Dong Calculator (`dong.py`)
Splits a restaurant bill between friends, including service/tip.
- Checks user input (no crash on letters or zero)
- Formats numbers like 2,200,000

## 2. To-Do List (`todo.py`)
A simple to-do app in the terminal.
- Add, show and remove tasks
- Saves tasks to a file, so they stay after closing

## How to run
python dong.py
python todo.py
